# Filmoo 🎬

Filmoo is a modern, responsive movie discovery application built with **React** and **Vite**. It allows users to browse through a collection of movies, search for specific titles, and view detailed information about each film.

## 🚀 Features

- **Movie Discovery**: Browse a curated list of movies on the home page.
- **Advanced Search**: Quickly find movies by title using the integrated search bar.
- **Detailed Information**: Click on any movie to view its details, including posters and descriptions.
- **Pagination**: Seamlessly navigate through multiple pages of movie results.
- **Modern UI**: A clean, dark-themed interface optimized for a premium user experience.

## 🛠️ Tech Stack

- **Frontend**: [React 19](https://react.dev/)
- **Build Tool**: [Vite](https://vitejs.dev/) (using `rolldown-vite`)
- **Routing**: [React Router 7](https://reactrouter.com/)
- **Data Fetching**: [Axios](https://axios-http.com/)
- **Styling**: Vanilla CSS

## 📦 Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) (latest LTS recommended)
- [npm](https://www.npmjs.com/)

### Installation

1. **Clone the repository**:
   ```bash
   git clone <repository-url>
   cd filmoo/filmoo
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Run the development server**:
   ```bash
   npm run dev
   ```

4. **Open in browser**:
   Navigate to `http://localhost:5173/` to see the application in action.
